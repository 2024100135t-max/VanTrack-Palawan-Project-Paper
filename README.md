VanTrack Palawan

Shuttle Van Terminal Schedule, Seat Availability, Booking and Rental Management System

VanTrack Palawan is a Flutter-based application designed to modernize shuttle van transportation management in Palawan. It provides an organized platform for managing trip schedules, seat availability, passenger bookings, van rentals, and transportation operations.

Project Overview

VanTrack Palawan aims to simplify the process of finding available shuttle trips, managing reservations, and organizing van rental transactions through a user-friendly digital platform.

Key Features

- User Authentication – User registration and login.
- Dashboard – Centralized access to application features.
- Trip Management – View routes, schedules, and trip information.
- Seat Availability – Check available seats for scheduled trips.
- Passenger Booking – Manage passenger trip reservations.
- Van Rental Management – Submit and manage van rental requests.
- Fleet and Inventory Management – Organize vehicle information and records.
- Booking History – Review previous passenger reservations.
- Rental History – Track rental transactions and records.
- Reports and Transactions – Organize operational and transaction information.

Installation and Setup

1. Install Flutter SDK.
2. Install Visual Studio Code.
3. Clone or download the project source code.
4. Open the project directory.
5. Run the following commands:

```bash
flutter pub get
flutter run -d chrome
```

Android Testing

```bash
flutter devices
flutter run
```

Project Goal

The goal of VanTrack Palawan is to provide a convenient, organized, and accessible transportation management solution that can help improve shuttle van scheduling, passenger reservations, seat monitoring, and van rental operations in Palawan.
